El tipo de máquina de cada negocio se obtiene de su nombre en Bitrix24. No importan las mayúsculas ni las tildes, y el nombre puede incluir otras palabras: "Torno CNC · Pérez" se reconoce como Torno CNC.

La tabla muestra, para cada tipo, ejemplos de nombres que se reconocen. Si el nombre del negocio no incluye ninguno, el negocio se cuenta como "Otro / Sin clasificar" en [[Negocios Bitrix24]].

{{tabla_maquinas}}

Cuando un nombre menciona más de un tipo, se toma el más específico. Por ejemplo, "centro de torneado" se cuenta como Torno CNC y no como Centro de mecanizado, y "láser de chapa y tubo" como Cortadora láser dual.

Si un nombre que se usa habitualmente no se reconoce, avisar al administrador de la aplicación para agregarlo.
